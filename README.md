# Leaf OS 5.0

Leaf OS 5 是一个基于 PowerPoint 制作的虚拟操作系统界面，旨在通过 PPT 的交互功能模拟操作系统的用户体验。  
> **Beta开发中，非完整作品**

---

## 开发工具

- **Microsoft PowerPoint**：用于开发和使用 PPT 文件。需 2019 或以上版本。
> **注意**：请勿使用 WPS 或其他非 Microsoft 系列的办公软件。

---

## 开始使用

- 直接从发行版或“源码”下载使用。

---

## 注意事项

- 必须使用 Microsoft 系列的 PowerPoint 软件，且版本为 2019 或以上版本，否则部分功能和动画可能无法正常使用和显示。
- 由于文件暂未启用宏，因此无需担心宏相关问题，但后续开发中可能会启用宏功能，请留意相关提示。
- OS 5系列全部使用vivo Sans字体
